# Лабораторная работа №1 — Первичное исследование и оценка качества данных

Учебный проект по дисциплине «Введение в интеллектуальный анализ данных». Выполняется на датасете Pokémon (6 поколений, включая мега-эволюции и альтернативные формы). Цель — описать данные в терминах задач ИАД, выполнить первичный обзор структуры и типов, провести аудит качества (пропуски, дубликаты, подозрительные значения, выбросы), построить осмысленные визуализации и оформить результаты в воспроизводимом виде.

## Структура проекта

- `README.md` — описание проекта и инструкции по запуску.
- `.gitignore` — исключения для git.
- `data/Pokemon.csv` — датасет (800 × 13).
- `notebooks/01_data_understanding.ipynb` — основной анализ.
- `report/quality_report.md` — текстовый отчёт о качестве данных.

## О датасете

`Pokemon.csv` — данные о покемонах из шести поколений (включая мега-эволюции и альтернативные формы). Размер: 800 строк × 13 столбцов. Признаки: идентификация (`#`, `Name`); типы (`Type 1`, `Type 2`); боевые характеристики (`HP`, `Attack`, `Defense`, `Sp. Atk`, `Sp. Def`, `Speed`, `Total`); поколение (`Generation`); легендарность (`Legendary`). Смешанные типы: числовые, категориальные, булевы.

## Требования и запуск

Требуется Python 3.8 или выше. Установка зависимостей одной командой в PowerShell или терминале: `python -m pip install --upgrade pip` и затем `python -m pip install jupyter notebook pandas numpy matplotlib seaborn`. Если команда `jupyter` не распознаётся системой — это нормально на Windows; используй запуск через модуль Python: `python -m notebook notebooks/01_data_understanding.ipynb`. Альтернативный вариант — открыть `.ipynb` файл в VS Code с установленным расширением Jupyter и выбрать нужное ядро Python. Все ячейки ноутбука выполняются последовательно сверху вниз без ручных правок; для воспроизводимости используется фиксированный `RANDOM_STATE = 42`.

## Цели работы

1. Описать датасет в терминах задачи ИАД (заказчик, вопросы к данным). 2. Выполнить первичный обзор: размер, структура, типы, базовая статистика. 3. Провести аудит качества данных: пропуски, дубликаты, подозрительные значения, выбросы. 4. Построить осмысленные визуализации для разведочного анализа. 5. Оформить результаты в воспроизводимом виде.

## Основные выводы

Датасет объёмный (800 записей), имеет смешанные типы признаков и содержит осмысленные пропуски (`Type 2` пуст примерно в 48% строк — это биологически обосновано, у покемона может не быть второго типа). Полных дубликатов нет, имена покемонов уникальны, но национальный номер `#` повторяется у мега-форм. Основные проблемы — неудобные имена столбцов (пробелы и точки в `Type 1`, `Sp. Atk`, `Sp. Def`) и потенциальная несогласованность `Total` с суммой характеристик. После нормализации имён столбцов и обработки `Type 2` датасет полностью пригоден для задач классификации (`Legendary`, `Type 1`), кластеризации по архетипам и анализа игрового баланса между поколениями.
