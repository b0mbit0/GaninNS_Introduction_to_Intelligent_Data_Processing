# GaninNS_Introduction_to_Intelligent_Data_Processing
# Лабораторная работа №1

Первичный анализ датасета Pokemon.csv (характеристики покемонов, поколения 1-6).

## Как запустить
Установить зависимости:
pip install pandas numpy matplotlib seaborn jupyter

Открыть `lab1/analysis.ipynb` и выполнить все ячейки.

## Файлы
- `data/pokemon.csv` — данные
- `lab1/analysis.ipynb` — ноутбук с анализом
- `report.md` — отчёт
